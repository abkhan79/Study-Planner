## 🛠️ Technologies Used
* **Frontend UI Layout:** HTML5, CSS3
* **Logic & Sorting Routing:** JavaScript (Vanilla ES6)
* **Data Storage:** Browser Client-Side Memory (`localStorage`)

## ⚙️ How to Run the App Locally
No special server installation or database setup is needed to test this project version.

1. Download and unzip the project directory to your local computer.
2. Open the project folder and locate the `index.html` file.
3. Double-click `index.html` to open it. It will run instantly inside any standard modern web browser (such as Safari, Chrome, or Firefox).

## ⚠️ Known Limitations
* Since data is written directly to the web browser's `localStorage` cache, clearing your browser history or changing to a different device will reset your active tracking dashboard data.
